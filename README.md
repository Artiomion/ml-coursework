## Running the notebooks

Tabular and image datasets are not included in the repository. Each notebook identifies its data and explains where to obtain it or how to provide it. Audio recordings for lessons 40 and 41, other audio examples, and generated recordings remain in the repository where available. Most use Python and Jupyter; libraries vary by lesson and include NumPy, pandas, scikit-learn, PyTorch, TensorFlow, OpenCV, and Transformers. Some examples also need external datasets, pretrained weights, a GPU, or a graphical display.

Saved outputs include results from full runs and earlier experiments. The notebook introductions identify cases where code changed after the saved run. Camera and interactive video examples were not run during cleanup; some audio-generation and separation examples also retain earlier outputs or have not been rerun.

Dataset and model licenses apply separately. Check the linked sources before reusing them.
